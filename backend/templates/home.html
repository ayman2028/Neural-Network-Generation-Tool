Create or Browse

Start by creating a new neural network or browsing existing ones in the library. Define your network architecture by specifying the number of layers and neurons.

Set up each layer with custom parameters. Choose activation functions, neuron counts, and other layer-specific configurations to match your needs.

Our tool automatically generates optimized HDL (Verilog) code for your neural network architecture. The code is ready for hardware synthesis and deployment.
